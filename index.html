    01 / INSTALL

    Start with one repository.

    Clone the project and install the portable skill for Codex. The renderer needs Python 3.10 or newer.

    git clone https://github.com/Hisernberg/archdiagram-studio.git
cd archdiagram-studio
python scripts/install_skill.py --agent codex

    Claude: use --agent claude. Other agents: read skills/draw-architecture/SKILL.md. PNG/PDF conversion additionally needs Inkscape; TikZ verification needs TeX.

    02 / DESCRIBE

    The prompt is composed locally. No model calls, account keys, or uploads are used by this gallery.

    01

    Meaning before styling.

    Every arrow makes a claim. Check evidence, dimensions, and residual origins before polishing the figure.

    02

    Source you can revise.

    Keep real text and shapes in SVG, geometry in JSON, and equations in native TikZ.

    03

    Render. Inspect. Refine.

    Geometry checks catch common problems. Final visual review checks the figure people will actually see.
